# VBA Automation Suite

A collection of Excel VBA tools built to automate manual, repetitive office tasks — including form-based data entry and multi-file management.

## 📊 Overview
This project combines multiple VBA automation tools: a UserForm-based Registration System for structured data entry, and a set of macros for handling multiple Excel files at once (combining, splitting, and counting).

## 🛠️ Tools Used
- Microsoft Excel
- VBA (Visual Basic for Applications)
- UserForms

## ✨ Features
- UserForm-based Registration System with dynamic dropdowns for date of birth and gender
- Input validation and auto-save to worksheet
- Macros to combine multiple regional Excel files into one master file
- Macro to extract each sheet into a separate workbook
- Macro to count files by type in a folder

## 📁 Use Case
File Management & Form Automation

## 📌 Key Skills Demonstrated
Process Automation, Data Accuracy, Record Management
